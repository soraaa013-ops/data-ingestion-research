# 深度调研：从业务系统搬到 ML 平台，中间究竟发生了什么？

建议先读根目录的[客服工单教程](../../README.md)。这一组文档继续使用那个例子，但把问题扩展到企业共享数据湖、托管集成和自建平台。

我们会追踪一条工单从创建、导出、修改、删除到训练版本发布的全过程。所有数值和工单均为教学构造，不冒充实测。厂商事实链接到原文；阅读卡记录边界；方案选择是本项目的综合判断。
