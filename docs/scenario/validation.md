# 可验证的假设与实验计划

任务 R09；仅制定计划，未连接生产、未运行实验。使用合成数据与隔离测试环境，不需要内部访谈。

## 比较设计

在相同数据分布、行宽、变更率和业务背景流量下，分别测试受控主库查询、专用副本、快照导出、水位增量和 CDC。快照生成、首次回填、稳态、失败恢复分开计量，不能只比较 CDC 稳态与查询全量。

先测无导入业务基线，再测各模式；固定并发等参数并记录配置版本。数据规模覆盖能体现索引命中和全表扫描差别的多档负载，避免只测空闲小表。

## 实验与通过依据

| 编号 | 注入条件 | 应观察结果 |
|---|---|---|
| V01 | 并发用户集中访问同一源 | 全局源预算生效，业务指标在预设阈值内 |
| V02 | 慢查询、取消、执行器退出 | 服务端任务停止或受明确上限约束 |
| V03 | 写文件成功后进程崩溃 | 重试不漏数、不重复发布 |
| V04 | 水位相等、迟提交、旧行修订 | 与期望集合一致，未覆盖语义显式报错 |
| V05 | 删除与乱序重放 | 物化状态正确，旧训练版本处理策略明确 |
| V06 | CDC 中断超过日志保留 | 检测恢复失败并重建，不能静默跳过 |
| V07 | DDL/类型变更 | 兼容变更版本化，不兼容隔离 |
| V08 | 授权运行中撤销 | 停止/阻断发布，保留可追溯结果 |
| V09 | manifest 提交前崩溃 | 训练不可发现半成品 |

阈值由目标 SLA/预算确定，目前未知，不伪造通用 5% 或固定并发数。
